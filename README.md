# 代扣代缴自然人增值税 Agent Skill

![version](https://img.shields.io/badge/version-v0.0.1-blue) ![license](https://img.shields.io/badge/license-MIT-green) ![python](https://img.shields.io/badge/python-3-yellow) ![evals](https://img.shields.io/badge/题库-3450题-orange)

把单位一个月付给**个人**的劳务费流水，交给 Agent，拿回《境内单位代扣代缴自然人增值税及附加税费申报表》和附列资料的草稿，外加一份异常清单。

2026 年 11 月 1 日起，单位给个人付讲课费、咨询费、设计费、稿费这类款项，要代扣增值税（财政部 税务总局公告2026年第28号）。**12 月 1 日至 15 日是第一次扣缴申报。** 手工做最费劲的是：同一个人同一天的钱要合并、按 1000 元起征点判断、含税要换算、附加税费要算减半，还要按 19 号公告的 14 列格式填。这个 skill 把这些都交给脚本。

> 仅辅助整理与计算，不构成税务意见。申报前请在自然人电子税务局（扣缴端）核对。

## 怎么用

把流水表（xlsx 或 csv）发给 Agent，说一句：

> 帮我把 11 月付给个人的劳务费整理成代扣增值税申报表。金额是含税的，按小规模减按 1%，单位在市区，附加税费减半。

口径没说全，它会先问；表里服务类别没填的，它会给建议，等你确认。没有表格也行，直接问：

> 讲课费 3000 元含税，要代扣多少增值税？

## 算法

| 规则 | 依据 |
|---|---|
| 同一人、同一天、在本单位的款项合并，满 1000 元（不含税销售额）全额计税，不满不扣但要申报 | 28号公告；即问即答 |
| 含税金额 ÷ (1 + 征收率) 换算销售额 | 19号公告填报说明 |
| 小规模减按 1%（执行至 2027-12-31），放弃优惠按 3%，残疾人免税 | 现行优惠政策 |
| 城建税 7% / 5% / 1%，教育费附加 3%，地方教育附加 2%，可选减半 | 附加税费规定 |
| 个体工商户、公司、平台已代办、2026-11-01 前付款、七类服务以外：不适用 | 28号公告；即问即答 |
| 已代开发票且已缴税：申报但不再扣 | 即问即答 |

七类服务：研发、软件、设计、咨询、广播影视节目（作品）制作、文化、教育服务。

## 为什么敢让 Agent 干这个

- **Agent 不算数。** 所有金额由 `scripts/calc.py` 算，Agent 只负责问口径、建议类别、解释结果。
- **不补数。** 缺证件号、日期、金额的行留在异常里，不填 0，不猜。
- **类别由人拍板。** Agent 只看“摘要”文字给建议，你确认后才写进去。
- **闸门自检。** 5 项自检（每行都有去处、两表合计一致、逐行复算等），任一不过就是草稿。
- **数据不出本机。** 脚本不联网；回复里证件号打码。
- **有红线。** 不碰个人所得税，不登录电子税务局，不替你提交，不帮你拆单、改日期少缴税。

## 测过多少

- 31 个单元测试，大多取自税务总局《即问即答》（2026-11-13）第 10–45 问的算例。
- 3450 道评测题，分 7 类（政策问答、口算、官方算例、月度流水、不规范格式、异常边界、行为），见 [evals/](evals/)。
- 发布前用 codex 当 Agent 实跑最早的 450 题，446 题通过（单次）。其余 3000 题还没实跑。

## 不做什么

个人所得税；登录或提交申报；退款更正；按月计税的自然人；skill 没内置的优惠。这些会列为异常，交给人处理。

## 还没核实

见 `references/policy.json` 的 `unverified`：减按 1% 的截止日、未达起征点行第 9–11 列填法、增值税和附加税费的减免性质代码等。欢迎有实操经验的会计提 issue。
