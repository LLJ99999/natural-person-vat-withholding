# 代扣代缴自然人增值税助手

版本 v0.0.2

给单位财务用的 AI 技能：把这个月付给个人的劳务费流水交给 AI，它帮你整理出《境内单位代扣代缴自然人增值税及附加税费申报表》和附列资料的草稿，并把有问题的款项单独列出来。12 月 1 日至 15 日是第一次申报。

> 本工具只帮你整理和计算，不构成税务意见。申报前请在自然人电子税务局（扣缴端）核对。

## 安装

**WorkBuddy**：点“技能”→“添加技能”→“上传技能”，选这个压缩包（不用解压）。

**Claude Code / Codex 等其他工具**：把压缩包解压到工具的技能文件夹里（Claude Code 是 `~/.claude/skills/`）。也可以直接对 AI 说：“请帮我安装这个技能：https://github.com/LLJ99999/natural-person-vat-withholding ，技能是仓库里的 natural-person-vat-withholding 文件夹。”

电脑需要装有 Python 3（可在 python.org 免费下载）。全程在你自己电脑上算，不联网上传数据。

## 怎么用

把流水表（Excel 或 CSV）发给 AI，然后说：

> 帮我把 11 月付给个人的劳务费整理成代扣增值税申报表。金额是含税的，按小规模减按 1%，单位在市区，附加税费减半。

没说清楚的，它会先问你；服务类别没填的，它会给建议，等你确认。不知道表怎么填，可以照着 assets 文件夹里的“示例流水.csv”填，或者让 AI 给你生成一张空表。

也可以直接问：“讲课费 3000 元含税，要代扣多少？”“个体户要不要代扣？”

## 你会拿到什么

| 文件 | 内容 |
|---|---|
| 申报表 | 按 19 号公告格式填好的 14 列 |
| 附列资料 | 附加税费 |
| 异常与提示 | 需要你处理的款项 |
| 不适用清单 | 不用代扣的款项，附理由 |

还有异常没处理时，文件名带“草稿_有异常_”，AI 也不会说“可以申报了”。

## 它不会做的事

不处理个人所得税，不登录电子税务局，不替你提交，不帮你拆单或改日期少缴税；缺的信息不会瞎填。
