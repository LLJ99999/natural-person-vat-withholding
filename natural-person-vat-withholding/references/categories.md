# 七类服务的范围（判断“服务大类”时读这个文件）

依据：28号公告第一条；范围按财政部 税务总局公告2026年第9号附件2《销售服务、无形资产、不动产注释》。
以下定义摘自国家税务总局《即问即答》（2026-11-13）第3–9问及第13、14问。

| 服务大类 | 9号公告定义（摘要） | 常见摘要写法（仅供参考，不是规则） |
|---|---|---|
| 研发服务 | 就新技术、新产品、新工艺或新材料及其系统进行研究与试验开发 | 技术开发费、研发合作费、实验费 |
| 软件服务 | 软件开发、软件维护、软件测试 | 外包开发、程序开发、测试费、系统维护 |
| 设计服务 | 把计划、规划、设想通过文字、语言、图画、声音、视觉等形式传递出来：工业、平面、包装、动漫、网游、展示、网站、机械、工程、广告设计，创意策划，文印晒图等 | 海报设计、LOGO、UI、装修设计、策划 |
| 咨询服务 | 提供信息、建议、策划、顾问：金融、软件、技术、财务、税收、法律、管理、健康等咨询；**翻译、市场调查按咨询服务** | 专家咨询费、顾问费、评审费、独立董事津贴、翻译费 |
| 广播影视节目（作品）制作服务 | 节目和作品制作，含策划、采编、拍摄、录音、素材制作、剪辑、翻译（编译）、字幕、特效等 | 拍摄费、剪辑费、配音、字幕、后期 |
| 文化服务 | 文艺创作、文艺表演、文化比赛、图书/档案、文物和非遗保护，组织文化/科技/宗教活动，游览场所 | 演出费、稿费（文艺创作）、评委费（文化比赛） |
| 教育服务 | 学历教育；非学历教育（各类培训、演讲、讲座、报告会）；教育辅助（测评、考试、招生） | 讲课费、讲座费、培训费、监考费、阅卷费 |

## 官方已明确的判断

- 外部独立董事津贴 → 咨询服务（第13问）
- 专家评审科研项目成果 → 咨询服务（第14问）
- 法律知识讲座 → 非学历教育服务（第41问）
- 经纪代理服务 → **不属于**七类（第11问）

## 判断规则（给 AI）

1. 只看“摘要/用途”文字，不看姓名和证件号。
2. 只有一个类别明显成立时才给建议；两个都说得通（例如“稿费”可能是文化服务里的文艺创作，也可能根本不是服务），写 `待人工确认` 并说明两种可能。
3. 劳务明显不在七类里（运输、维修、保洁、租赁、销售商品、经纪代理）时，建议 `不适用`，并写理由。
4. 你的建议只是建议。写进 `类别确认表.csv` 前，必须让用户逐行确认或修改。
